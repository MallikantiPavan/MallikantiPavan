### 🚀 Featured Projects

#### 🧬 Normative-Deviation Guided Asymmetry-Aware Graph Transformer for FCD Detection
*IIT Madras — Research Internship, May 2026–Present*
A novel graph neural network pipeline for detecting subtle Focal Cortical Dysplasia lesions on MRI, built on the Destrieux-148 cortical atlas.
- Designed a **z-score-derived disease-prior attention bias** mechanism that modulates attention logits with normative deviation scores — the pipeline's core novel contribution
- Benchmarked against MELD Graph, BrainDGT, and BrainHGT on the ds004199 and IDEAS (ds005602) datasets
- Diagnosed and resolved a critical false-negative case (coordinate-space mismatch) in a competing pipeline, establishing a key comparative finding
- Addressed severe class imbalance (~1.5% positive nodes) with Focal Loss, graph augmentation, and k-fold cross-validation

#### ✈️ CA-YOLONet — Drone Detection Under Adverse Weather
*Research Intern, IIIT Tiruchirappalli, Nov 2025–Jan 2026*
- Modified YOLO-based object detection framework for small aerial target detection in cloudy/evening conditions
- Redesigned anchor configurations and architecture, achieving **67.3 mAP@50:95**
- Ran systematic ablation studies to isolate the contribution of each architectural change
- Manuscript submitted to the International Conference on Intelligent Computing and Computer Vision

#### 🩻 ChestAI — Chest X-Ray Classification Web App
DenseNet + ECA attention + Grad-CAM explainability, served via a FastAPI/PyTorch backend with a polished frontend for interactive diagnosis visualization.

#### 💳 Credit Card Fraud Detection
Logistic Regression model achieving **95% accuracy**, deployed with FastAPI + Streamlit and hosted for real-time scoring.

#### ⚓ Titanic Survival Predictor
